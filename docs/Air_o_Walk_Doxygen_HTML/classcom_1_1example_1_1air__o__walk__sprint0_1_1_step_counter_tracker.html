Descripción detallada

Gestiona el seguimiento de pasos del usuario mediante sensores del dispositivo.

Esta clase implementa un sistema de conteo de pasos que utiliza los sensores de hardware del dispositivo Android. Intenta usar TYPE_STEP_COUNTER (más preciso) y si no está disponible, usa TYPE_STEP_DETECTOR como alternativa.

Funcionalidades principales:

  • Detección automática de sensores disponibles
  • Conteo de pasos por sesión
  • Reset de sesión para iniciar nuevo conteo
  • Notificación de cambios mediante listener
