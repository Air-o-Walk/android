Descripción detallada

Modelo de datos que representa un canjeo de premio.

Esta clase encapsula la información asociada a un canjeo realizado por un usuario, incluyendo el código del cupón, la fecha de redención, el premio canjeado y los puntos requeridos.

Se utiliza principalmente para transportar datos entre la capa de comunicación con el backend y la interfaz de usuario.
