Descripción detallada

Encapsula la lógica de negocio para la edición del perfil de usuario.

Esta clase gestiona las operaciones necesarias para actualizar los datos básicos del perfil de un usuario autenticado, incluyendo:

  • Nombre de usuario
  • Correo electrónico
  • Contraseña (con verificación previa)

La comunicación con el backend se realiza mediante peticiones REST y los resultados se notifican de forma asíncrona a través de interfaces de callback.
