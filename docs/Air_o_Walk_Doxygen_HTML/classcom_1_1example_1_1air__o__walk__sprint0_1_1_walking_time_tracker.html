Descripción detallada

Gestiona el seguimiento del tiempo de caminata del usuario.

Esta clase proporciona funcionalidades para medir y controlar el tiempo de actividad del usuario durante sus caminatas. Permite iniciar, pausar, reanudar y detener el seguimiento, además de calcular métricas derivadas como velocidad y ritmo.

Funcionalidades principales:

  • Seguimiento de tiempo en tiempo real
  • Control de inicio, pausa y reanudación
  • Cálculo de tiempo transcurrido en diferentes unidades
  • Formateo de tiempo para visualización
  • Cálculo de velocidad y ritmo basado en distancia
  • Notificaciones periódicas mediante listener
