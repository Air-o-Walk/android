Descripción detallada

Clase con métodos estáticos para conversiones entre diferentes tipos de datos.

Esta clase proporciona funciones de utilidad para convertir entre strings, bytes, UUIDs, números enteros y otros tipos de datos. Es especialmente útil para trabajar con datos de beacons y comunicaciones de bajo nivel.

Funcionalidades principales:

  • Conversiones entre strings y bytes
  • Conversiones entre UUID y diferentes representaciones
  • Conversiones entre arrays de bytes y números (int, long, float)
  • Formateo hexadecimal de bytes
